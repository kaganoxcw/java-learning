# Java 学习笔记仓库

> 配套「学期中 13 周计划（2026 秋）」的笔记与刷题记录仓库
> 计划文件：`Java-13周学习计划-学期中版.md`

---

## 一、每天怎么用（3 分钟流程）

1. 学完一个知识点 → 让 DSH 把笔记**骨架**生成到 `notes/` 对应目录
2. **自己补「我的理解」和「踩坑记录」两栏**（这两栏不能让别人代写）
3. 睡前提交：
   ```bash
   git add .
   git commit -m "docs: 第X天 - 集合框架笔记"
   ```
4. 每周日推送：`git push`

---

## 二、目录说明

| 目录 | 放什么 | 命名规范 |
|---|---|---|
| `notes/` | 知识点笔记，按 7 大主题分文件夹 | `序号-知识点名.md` |
| `leetcode/` | 刷题记录 | `题号-题名.md`（题号补足 4 位） |
| `bugs/` | 踩坑记录 | `日期-问题简述.md` |
| `weekly/` | 周复盘 | `week01.md` |
| `snippets/` | 可复用代码片段 | `用途.md` |

> **`bugs/` 是最值钱的目录。** 知识点书上网上都有，你踩过的坑是你独有的，面试时最能讲。

## 四、提交信息规范

| 前缀 | 用途 | 例子 |
|---|---|---|
| `docs:` | 笔记类 | `docs: 添加 HashMap 笔记` |
| `feat:` | 新项目 / 新功能 | `feat: 学生管理系统-添加功能` |
| `fix:` | 修 bug | `fix: 修复成绩输入为负数未校验` |
| `refactor:` | 重构 | `refactor: 数组存储改为 ArrayList` |
| `chore:` | 杂项 | `chore: 更新 .gitignore` |

## 五、笔记质量自检

写完一条笔记，问自己：

- [ ] 「我的理解」是我自己写的，不是复制的吗？
- [ ] 有至少一段我自己敲过并跑通的代码吗？
- [ ] 有踩坑记录吗？（没有踩坑说明学得太浅）
- [ ] 有"还没搞懂的地方"吗？（没有说明没深入思考）
