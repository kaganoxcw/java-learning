## 一、一句话概括

Java 是强类型语言，每个变量必须先声明类型才能使用，8 种基本类型直接存值，其余都是引用类型。

---

## 二、我的理解

基本类型就像 8 个不同尺寸的盒子，盒子多大就装多大的数，装不下就报错。
引用类型存的是"地址"而不是值本身——比如 String 存的其实是对象在堆里的位置。

---

## 三、关键点

| 要点 | 说明 |
|---|---|
| 8 种基本类型 | byte(1) short(2) int(4) long(8) float(4) double(8) char(2) boolean(1) |
| 默认整数类型 | 字面量 100 默认是 int |
| 默认小数类型 | 字面量 3.14 默认是 double |
| 自动类型转换 | 小范围 → 大范围，自动 |
| 强制类型转换 | 大范围 → 小范围，要写 `(类型)`，可能丢精度 |
| final | 常量，只能赋值一次 |

---

## 四、代码示例

```java
public class TypeDemo {
    public static void main(String[] args) {
        int a = 10;
        long b = 100L;          // long 字面量要加 L
        float c = 3.14F;        // float 字面量要加 F
        double d = 3.14;

        // 自动类型转换：int -> double
        double e = a;
        System.out.println(e);  // 10.0

        // 强制类型转换：double -> int，小数部分直接截断（不是四舍五入！）
        int f = (int) 3.99;
        System.out.println(f);  // 3

        // 精度丢失案例
        System.out.println(0.1 + 0.2);   // 0.30000000000000004

        final int MAX = 100;
        // MAX = 200;   // 编译报错
    }
}
```

---

## 五、踩坑记录

**现象**：`int f = (int) 3.99;` 我以为结果是 4，实际是 3。

**原因**：强制类型转换是**直接截断小数部分**，不是四舍五入。

**解法**：需要四舍五入时用 `Math.round(3.99)`。
