## 一、题目要点

给一个**升序**数组和目标值，找到就返回下标，找不到返回 -1。要求 O(log n)。

---

## 二、我的思路

每次取中间位置，和 target 比较：
- 相等 → 返回
- 中间值 < target → 目标在右半边，left = mid + 1
- 中间值 > target → 目标在左半边，right = mid - 1

循环条件用 `left <= right`（因为 mid 位置本身也可能是答案）。

---

## 三、代码

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {
            // 防止 (left + right) 溢出
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return -1;
    }
}
```

---

## 四、复杂度

- 时间：O(log n)
- 空间：O(1)

---

## 五、卡在哪 / 学到了什么

**卡点**：一开始写成 `while (left < right)`，结果 target 正好在边界时会漏掉。

**关键**：
1. 循环条件是 `left <= right`，因为区间是闭区间 `[left, right]`
2. `mid` 用 `left + (right - left) / 2` 而不是 `(left + right) / 2`，防整数溢出
